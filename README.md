# 📊 Siemens AP Analytics Dashboard

## 🔍 Overview
This project simulates real-world Accounts Payable analytics using SQL, Power BI, and Power Query. It focuses on analysing invoice data, identifying payment delays, and uncovering operational inefficiencies in finance operations.

---

## 🛠 Tools Used
- SQL (PostgreSQL)
- Power BI
- Power Query
- Microsoft Excel

---

## 📁 Dataset
- 6 relational tables:
  - Invoices
  - Vendors
  - Payments
  - Purchase Orders
  - PO-Invoice Matching
  - Credit Notes
- Multi-currency data (GBP, USD, EUR)
- 1,500+ records

---

## 📈 Key Insights
- Analysed **£144.7M total spend**
- Identified **£13.6M overdue payments**
- Found **23.7% on-time payment rate**
- Highlighted inefficiencies in invoice processing and payment cycles

---

## 📊 Dashboard Features
- Invoice aging analysis
- Vendor performance tracking
- Payment trend analysis
- KPI dashboards

---

## 🧹 Data Cleaning
- Standardised date formats (UK/US)
- Removed duplicate invoices
- Handled currency inconsistencies
- Cleaned missing and invalid records

---

## 📌 Outcome
This project demonstrates the ability to work with financial data, perform analysis, and build business-focused dashboards to support decision-making.
